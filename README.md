# Cancer Var — учебный классификатор опухолей

Учебный проект на Python и scikit-learn: обучает модель на встроенном наборе `load_breast_cancer`, сохраняет её и предоставляет HTTP API для получения оценки модели.

> **Важно:** это демонстрация машинного обучения, а не медицинский инструмент. Результат модели нельзя использовать для диагностики, скрининга или выбора лечения.

## Данные

Встроенный набор Wisconsin Diagnostic Breast Cancer содержит 569 строк, 30 числовых признаков и метку `malignant` или `benign`. Это **табличные признаки, вычисленные по оцифрованным изображениям образцов**, а не сами снимки. Модель не анализирует медицинские изображения.

## Что внутри

- `StandardScaler` и `LogisticRegression` в одном конвейере;
- фиксированное разбиение на обучающую и тестовую выборки;
- метрики ROC AUC, точности, полноты и F1;
- сохранение модели через `joblib`;
- API на FastAPI для получения оценки модели.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\\Scripts\\activate
pip install -e .
python -m cancer_var.train
uvicorn cancer_var.api:app --reload
```

После запуска API доступны документация `/docs` и проверка состояния `/health`.

Для предсказания отправьте список из 30 чисел в том же порядке, что и `feature_names` из scikit-learn:

```bash
curl -X POST http://127.0.0.1:8000/predict \
  -H 'Content-Type: application/json' \
  -d '{"features": [17.99, 10.38, 122.8, 1001, 0.1184, 0.2776, 0.3001, 0.1471, 0.2419, 0.07871, 1.095, 0.9053, 8.589, 153.4, 0.006399, 0.04904, 0.05373, 0.01587, 0.03003, 0.006193, 25.38, 17.33, 184.6, 2019, 0.1622, 0.6656, 0.7119, 0.2654, 0.4601, 0.1189]}'
```

Ответ содержит `model_probability_malignant` — вероятность класса, рассчитанную моделью на этом наборе данных. Это не индивидуальная клиническая вероятность заболевания.

## Ограничения

- Маленький учебный набор не представляет все население и все условия сбора данных.
- Высокая метрика на отложенной части этого набора не доказывает пригодность модели в клинике.
- Вероятности модели не откалиброваны для клинических решений.
- Не отправляйте в демонстрационный API персональные медицинские данные.


## Проверка

```bash
pip install pytest httpx
pytest -q
```

API `/features` возвращает названия признаков в ожидаемом порядке. Обучение сохраняет метрики в `artifacts/metrics.json`. После переобучения перезапустите сервер: модель кэшируется в памяти. Загружайте только собственные доверенные joblib-файлы.
